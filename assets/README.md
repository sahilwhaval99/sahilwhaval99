# 🖼️ Project Screenshots & Assets Guide

Drop your real application screenshots or screen recordings into this directory:

- `assets/projects/turbine-preview.png` (or `.gif`): Dashboard / telemetry stream view of **Turbine Predictive Maintenance**.
- `assets/projects/netcapacity-preview.png` (or `.gif`): Capacity planner or forecast explorer view of **NetCapacity-AI**.
- `assets/projects/shortestpath-preview.png` (or `.gif`): Graph visualization canvas of **Shortest Path Visualizer**.
- `assets/projects/don-preview.png` (or `.gif`): UI or terminal session view of **DON v3.0 AI Assistant**.

> **Note**: Recommended format is PNG or WebP under 1.5 MB, or an optimized GIF under 3 MB.
